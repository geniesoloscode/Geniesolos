# GenieSolos Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/store` page on geniesolos.com with a multi-item cart that checks out through one Stripe Checkout Session created by a Lambda at `/api/checkout`.

**Architecture:** Static page (external css/js, CSP-compliant) + localStorage cart + one zero-dependency Node 22 Lambda behind the existing CloudFront distribution. Client sends product keys only; the Lambda maps keys to Stripe price IDs and creates the session.

**Tech Stack:** Plain HTML/CSS/JS (no framework, matching the site), Node 22 Lambda via raw Stripe REST API, PowerShell setup scripts, AWS CLI v2, `node --test` for unit tests.

**Spec:** `docs/superpowers/specs/2026-08-14-store-design.md` — read it before starting any task.

## Global Constraints

- **CSP (hard requirement):** CloudFront serves `style-src 'self'`, `script-src 'self'` + one hash. NO inline `<style>`, NO inline `<script>` except the head theme snippet copied **byte-identical** from `index.html` lines 19–33 (the `(function () { var pick = null; ...})();` block, including the `// shareable / testable` comment). All other CSS/JS in external files.
- **Design tokens:** copy `:root` and `:root[data-theme="dark"]` token blocks verbatim from `css/terms.css` (they mirror `css/style.css`). Fonts: Fraunces (display), Space Grotesk (body), JetBrains Mono (labels/prices) via the same Google Fonts `<link>` used in `terms.html`.
- **Deploy is default-deny:** new site files must be explicitly wired into BOTH `.github/workflows/deploy.yml` and `scripts/deploy.ps1` (Task 4). `api/`, `tests/`, `docs/`, `scripts/` must NOT be added to the sync whitelist.
- **Cache busting:** any changed/new css/js is referenced with `?v=20260815`.
- **Product keys** (the only vocabulary shared by store-cart.js, store.js, and the Lambda): `lifeline`, `presence`, `transformation`, `storefront-zero`, `storefront-build`, `server-care`, `db-care`, `workspace-admin`. Base plans: first five. Storefront plans: `storefront-zero`, `storefront-build`. Quantity items (qty 1–20): `server-care`, `db-care`.
- **Commits:** one per task, message explains why, ends with `Co-Authored-By:` line per repo convention.
- All PowerShell scripts: `$ErrorActionPreference = 'Stop'`, `--region us-east-1` on every AWS call (repo convention; see scripts/deploy.ps1 header comment).

### Task 1: Cart rules engine (`js/store-cart.js`) — model: Opus

**Files:**
- Create: `js/store-cart.js`
- Create: `tests/store-cart.test.mjs`

**Interfaces:**
- Consumes: nothing (pure logic, no DOM).
- Produces: a `GSCart` object exposed BOTH as `window.GSCart` (browser) and `module.exports` (node tests), with exactly:
  - `GSCart.CATALOG` — `{ [key]: { name, monthly, once, kind, maxQty } }` where `kind` ∈ `'base' | 'storefront-base' | 'addon' | 'storefront-addon'`; `monthly`/`once` are integer cents; `maxQty` is 1 or 20.
  - `GSCart.add(items, key, qty)` → `{ items, replaced }` — new items array; `replaced` is the display name of a removed base plan or `null`. Adding a second base plan replaces the first. Adding an addon without its prerequisite throws `Error` with a user-readable message.
  - `GSCart.remove(items, key)` → new items array. Removing the last base plan also removes now-orphaned addons (`workspace-admin` when no storefront base remains; all addons when no base remains) and reports them: returns `{ items, dropped: [names] }`.
  - `GSCart.setQty(items, key, qty)` → new items array (clamped 1..maxQty, integers only).
  - `GSCart.totals(items)` → `{ monthly, once }` in cents.
  - `GSCart.validate(items)` → `{ ok: true }` or `{ ok: false, error }` — same rules the Lambda enforces: 1–10 unique known keys, exactly one base plan, `workspace-admin` requires a storefront base, qty bounds.
  - `items` is always `[{ key, qty }]`, never mutated in place.

**Catalog values** (from the spec, cents): lifeline 29900/mo, presence 64900/mo, transformation 99900/mo, storefront-zero 49900/mo, storefront-build 14900/mo + 450000 once, server-care 22500/mo (maxQty 20), db-care 17500/mo (maxQty 20), workspace-admin 19900/mo.

```js
import { test, beforeEach } from 'node:test';
import assert from 'node:assert/strict';
process.env.STRIPE_SECRET_KEY = 'sk_test_stub';
process.env.ALLOWED_ORIGIN = 'https://geniesolos.com';
process.env.PRICE_MAP = JSON.stringify({
  lifeline: ['price_l'], presence: ['price_p'], transformation: ['price_t'],
  'storefront-zero': ['price_sz'], 'storefront-build': ['price_sbm', 'price_sbo'],
  'server-care': ['price_sc'], 'db-care': ['price_dc'], 'workspace-admin': ['price_wa'],
});
const { handler } = await import('../api/checkout/index.mjs');
const ev = (body, extra = {}) => ({
  requestContext: { http: { method: 'POST', path: '/api/checkout' } },
  headers: { origin: 'https://geniesolos.com' },
  body: JSON.stringify(body), isBase64Encoded: false, ...extra,
});
let lastCall;
beforeEach(() => {
  lastCall = null;
  globalThis.fetch = async (url, opts) => {
    lastCall = { url, opts };
    return { ok: true, status: 200, json: async () => ({ url: 'https://checkout.stripe.com/c/s_123' }) };
  };
});

test('happy path returns the session url and sends the right params', async () => {
  const res = await handler(ev({ items: [{ key: 'storefront-build', qty: 1 }, { key: 'server-care', qty: 3 }] }));
  assert.equal(res.statusCode, 200);
  assert.equal(JSON.parse(res.body).url, 'https://checkout.stripe.com/c/s_123');
  const p = new URLSearchParams(lastCall.opts.body);
  assert.equal(p.get('mode'), 'subscription');
  assert.equal(p.get('consent_collection[terms_of_service]'), 'required');
  const prices = [...p.entries()].filter(([k]) => /line_items\[\d+\]\[price\]/.test(k)).map(([, v]) => v);
  assert.deepEqual(prices.sort(), ['price_sbm', 'price_sbo', 'price_sc'].sort());
});

test('two base plans rejected', async () => {
  const res = await handler(ev({ items: [{ key: 'lifeline', qty: 1 }, { key: 'presence', qty: 1 }] }));
  assert.equal(res.statusCode, 400);
});

test('foreign origin rejected', async () => {
  const res = await handler(ev({ items: [{ key: 'lifeline', qty: 1 }] }, { headers: { origin: 'https://evil.example' } }));
  assert.equal(res.statusCode, 403);
});
```
